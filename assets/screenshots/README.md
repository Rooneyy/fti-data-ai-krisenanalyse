Dieser Ordner dokumentiert die visuelle Entwicklung des Power-BI-Dashboards.

## Screenshot-Tipp

1. PBIX-Datei in Power BI Desktop oeffnen.
2. Seiten- und Visualisierungs-Panels ausblenden.
3. Ansicht auf "An Seite anpassen" stellen.
4. Screenshot als PNG speichern.
5. Datei mit dem passenden Namen in diesen Ordner legen.
